Lichess & Chess.com fair-play scanner

Checking engine… GitHub ↗ lichess.org ↗ chess.com ↗
Statistical screening, not a verdict

Look for engine-like patterns in a player's games.

Downloads a player's Lichess or Chess.com history, evaluates positions with Stockfish compiled to WebAssembly, and compares accuracy, centipawn loss, move timing and results with rating-appropriate baselines. Everything runs in this browser tab.

Read this first

No score is proof of cheating. Strong players, fast time controls and small samples can all look anomalous. Review the games and context.

Kept in this tab's memory only. Sent directly to Lichess and never stored.
How to create a token (free, no scopes needed)
  1. Open lichess.org/account/oauth/token.
  2. Click Create a token, give it any name (e.g. KnightWatch), leave all scopes unchecked.
  3. Copy the token and paste it above. Lichess now requires a token for the full game-export endpoint.
